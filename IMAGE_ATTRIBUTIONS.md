Storefront flower photos in `public/images/flowers` and `public/images/tulips` are local copies of real images sourced from Openverse-compatible providers.

Detailed attribution metadata for each imported photo is tracked in `image-attributions.json`, including:
- local file path
- search query used
- title and creator
- license
- source page
- original image URL

The existing rose files in `public/images/roses` were already present in the repository and were not changed by this update.
